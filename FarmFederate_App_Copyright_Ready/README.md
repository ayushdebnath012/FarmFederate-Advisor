# FarmFederate Advisor

FarmFederate Advisor is a Flutter app for tea disease detection, farm sensor monitoring, and privacy-preserving crop health guidance.

## Included

- Flutter source for Android, iOS, web, Linux, macOS, and Windows.
- Original app source under `lib/`.
- App icons and logo assets under `assets/` and platform resource folders.
- Firebase and backend configuration files needed by the app.

## Excluded

Build outputs, local IDE folders, logs, research reference sets, profile releases, PDFs, papers, and third-party sync corpora are not included in this copyright-ready app folder.

## Run

```sh
flutter pub get
flutter run
```

The backend URL is configured in `lib/constants.dart`.
